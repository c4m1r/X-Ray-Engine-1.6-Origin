- исправления дочерних окон: теперь сворачиваются нормально
- добавлена поддержка рендера D3D11 (показать скрин)
- добавлена поддержка горячего переключения backface (double sides) (показать скрин)
- параметр rfps повышен до 60 fps
- добавлен счетчик объектов в кадре - OBJ (показать скрин)
- новый набор шейдеров для рендера D3D11: shaders/ed11
- исправлен баг с множественным выделением источников света
- добавлена опция LOD Distance для оптимизации окна рендеринга и комфортной работы (показать скрин)
- добавлена опция Render Distance для оптимизации окна рендеринга и комфортной работы (показать скрин)
- Добавлено кэширование SRV текстуры на поверхности (убран per-draw lookup по строке).
- Добавлено кэширование флага прозрачности (strstr вынесен из горячего цикла).
- Добавлен bind instance buffer и топологии раз на батч; убран O(N²) обход render-буферов.
- Добавлен кэш батчей по dirty с гистерезисом камеры (сбор сцены при статичной камере практически обнулён, видимость через GPU frustum-cull).
- Добавлено кэширование счётчиков полигонов/вершин для оверлея статистики.
- Добавлена дедупликация per-frame update модели (раз на reference, а не на инстанс).
- Добавлена передача набора инструментов по const& (убрана копия multiset каждый кадр).
- Добавлены LOD-биллборды для растительности с настройкой LOD Distance в UI.
- Добавлена индексная геометрия (DrawIndexedInstanced): vertex shader гоняет уникальные вершины вместо углов треугольников.
- Добавлена vertex-cache optimization (Forsyth).
- Добавлен broad-phase ray-pick (ray-vs-AABB перед raycast): пикинг из секунд в миллисекунды.
- Добавлен инструмент Gizmo (показать скрин)
- Добавлен инструмент Center Pivot (показать скрин)
